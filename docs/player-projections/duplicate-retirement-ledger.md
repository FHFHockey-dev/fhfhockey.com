## Retirement order

1. **Quarantine operational hazards first:** audit the goalie-mixture route/table mismatch, the SECURITY DEFINER sKO RPC and live stale-cron references. This does not authorize a production change; it establishes the next controlled change set.
2. **Capture callers and data retention:** API/page telemetry, live scheduler inventory, database read/write ownership and historical-value requirements.
3. **Ship additive canonical contracts:** immutable player snapshot/model/vintage outputs and adapters selected after research approval.
4. **Migrate consumers in shadow:** Start Chart, FORGE UI, draft/dashboard and any external clients.
5. **Disable writers/jobs, observe, then remove:** preserve an explicit rollback/archive window and use active `supabase/migrations/` for database retirement.

The ledger should be updated—not rediscovered—when the final research architecture and live dependency audit arrive.
