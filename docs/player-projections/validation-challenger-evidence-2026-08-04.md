## Source audit

141,488 skater-game rows. All 47,150 target-season skater rows have an official
game team identity. Official NHL play-by-play A1+A2 matches the boxscore total
assist count on 47,031 target-season rows. The 119 mismatches remain eligible
for official total-assist scoring but are excluded from A1/A2 component-label
training.

WGO/NST fields remain excluded. Their event dates do not prove cutoff-time
availability, and their definition/rights gates remain unresolved.

## Assist decomposition decision

Official total assists remain the scored target and identity:

`E[assists] = E[primary assists] + E[secondary assists]`.

The 70:30 and 80:20 play-driver signals were calibrated using training rows
before each validation fold. Neither improved total-assist MAE:

| Population | Best ordinary total model | A1+A2 alternative | Calibrated 70:30 | Calibrated 80:20 |
| --- | ---: | ---: | ---: | ---: |
| Defense | 0.3840 | 0.3843 | 0.3937 | 0.3951 |
| Forward | 0.4044 | 0.4045 | 0.4156 | 0.4163 |

A1+A2 decomposition was useful diagnostically for sparse rows, but a
fold-trained history-adaptive router also lost out of fold. Therefore fixed
weights, independent component summation, and the router are not selected for
the validation serving artifact.

## Hits decision

For defense, a fold-trained linear context layer over the career-rate base won
with MAE 0.7961, ahead of 0.8026 for EWMA. Its inputs are the base candidate,
team/position rate, opponent-allowed position rate, home indicator, and rest
days. Coefficients are learned only from rows before each validation fold; no
hand-authored context weights or hard sparse-history routing rule is used.
The equivalent context candidates did not win for forwards, where career rate
remains selected at MAE 0.8933.

The Poisson-gamma position/player partial-pooling model also learned its prior
strength from development data, but did not beat the winners: defense MAE was
0.8336 and forward MAE was 0.9004. It is retained as a rejected ablation, not a
serving path.

## Rest-of-season status

The local schema, deterministic conditional/unconditional aggregation, private
read API, and dashboard table are implemented. An aggregate is valid only when
its component manifest covers every remaining scheduled game under one
schedule-revision hash. Unconditional totals fail closed unless every component
has a playing probability. The current historical-core challenger cannot yet
issue an early-season ROS row because it forecasts only H1–H10 and lacks
historical availability labels; it must not mislabel a next-10 partial sum as
rest of season.

## Local operational proof

The checksum-bound validation artifact was registered only in local Supabase
and replayed through the authenticated Next.js coordinator and local Python
worker. One H1 fixture run succeeded with four immutable conditional outputs:
forward/defense assists and hits. The defense-hit output exercised the selected
contextual model using cutoff-safe team and opponent rates from game-time roster
identity. All outputs retained `validation_only`; no hosted migration,
deployment, FORGE change, champion update, or lockbox read occurred.
