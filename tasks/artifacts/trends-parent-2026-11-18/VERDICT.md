## What the manager gets

The ownership and ADP tables show the Yahoo source date, target window and each row's observation dates. Different-length spans and older endpoints are disclosed. An established NHL ID gets a player link. An unresolved mover keeps its Yahoo name, team, eligibility, value and history and is marked “Yahoo listing.” The controls show only the response for the selected state. Changing filters from a later page requests page one directly. A failed or empty later page still offers Previous.

The new Trends-only PostgreSQL reader selects up to 1,000 source players in their existing player-ID and season order, with a final key tiebreaker for previously unspecified ties. It returns every non-null dated observation in two identically ordered arrays. The API reconstructs the full history before running the existing movement logic. Source season fallback, exact seasonal identity mapping, page size and cache lifetimes are preserved.
