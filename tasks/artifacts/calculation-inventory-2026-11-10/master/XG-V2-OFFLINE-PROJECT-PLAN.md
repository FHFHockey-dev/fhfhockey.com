## Proposed contract before any fit
Target: `P(goal on this attempt | information available at the shot)`, one row per `(gameId, eventId)` unblocked attempt. Goal is 1; eligible non-goal unblocked attempts are 0. Exclude shootouts, own goals and shots into the opponent's empty net from the standard xG/GSAx/xGA model; preserve separate exclusion counts. A shooter's own empty net is not an attacking-empty-net exclusion. Keep penalty shots separate from ordinary-play first-release model scope, with a visible unsupported/excluded count; if all-situation coverage including penalty shots is required, it needs its own defensible probability/validation contract rather than silent zero-fill. Blocked attempts are outside this conditional target, not negatives. Audit eligibility against the actual builder and event definitions.

Use normalized shot location/distance/angle, period and pre-shot time, verified pre-event manpower, and shot type only after checking recording availability/missingness is not outcome-coded. Begin with a small explicit allowlist. Unknown remains unknown; fit imputations, scales and categorical levels on training only. Shooter, goalie, team identity and season aggregates are not required for this baseline.

All context must be a strict backward prefix: pre-event score, prior events, current shift age only if derivable from an already-started shift. No shift end/duration learned later, full-possession duration/count, future rebound creation, current event result/type, miss reason, short-side miss, flurry membership, post-event score or season-end aggregates. A past rebound/rush flag is eligible only after proving its source event precedes this shot and its computation does not inspect later events. Same-clock events use deterministic authoritative ordering; unresolved order means omit that context. Never cross games using event ID alone. Record retrospective provider corrections and limit the claim to event-time reconstructed information unless historical publication snapshots exist.

Required tests: truncating or appending future events cannot change earlier features; swapping goal/miss outcome while holding allowed shot geometry/context fixed cannot change features; score-after-event mutation cannot change pre-shot score; reused IDs across games remain isolated; EN/own-EN/shootout/penalty-shot cases preserve the eligibility contract; all feature-version-1 inputs are rejected. Keep labels and eligibility metadata outside the model matrix.

## Offline implementation stages, after approval
1. Freeze source commit, environment, file hashes and a data manifest. Isolate a scratch copy, deny network, do not load `.env`, and prohibit repository writes. Create a read-only local file adapter around pure parser/builder/dataset functions.
2. Produce a coverage/provenance report before fitting: game/date/season counts, row/goal counts, duplicate and excluded events, geometry/manpower missingness, parser and strength versions, and correction timestamps. Match all official eligible goals to attempts; unexplained omissions stop the run.
3. Freeze game-level chronological partitions. Keep complete dates together: training < tuning validation < calibration < final test, with strictly disjoint date ranges. If using the existing three-split API, partition validation internally into tuning and calibrator subsets and record that ownership. Prefer a later season as final holdout if enough untouched data exists. Do not pick a boundary after inspecting model performance. Older already-inspected 2025-26 test games are development only.
4. Run a training-rate constant baseline, a compact geometry logistic model, then one regularized logistic candidate with a small predeclared L2 sweep selected using tuning data only. Record convergence/gradient/objective diagnostics. No broad booster search in this first milestone. A more complex challenger is a later ticket only if the simple candidate has a demonstrated shortfall.
5. Fit a predeclared calibrator (e.g. Platt; tie-pooled isotonic only with adequate calibration evidence) solely on calibration data. Freeze the exact model, transforms, calibrator and scorer hash before unlocking final holdout. Verify the same artifact's persisted scorer matches offline probabilities row for row.
6. Evaluate once on untouched later games. Report log loss, Brier, reliability bins, calibration intercept/slope or equivalent diagnostics, current gate tests, and AUC as secondary discrimination only. Compare with both training-rate constant and the gate's stronger test-rate constant. Add game-block bootstrap confidence intervals for score differences and calibration uncertainty, since within-game shots are not independent. Predeclare subgroups: strength, rebound/nonrebound when used, shot type/distance, season/game type, and missing-feature status. Sparse cells are insufficient evidence, not passes.
7. Deliver an offline evidence pack and explicit go/no-go. No registry registration, shadow database scoring, aggregate rebuild or deployment is included.

## Go/no-go and acceptance
GO means eligible for owner review, not permission to ship. Require: complete lineage/eligibility tests; v2 only; converged reproducible fitting; strictly chronological unexposed holdout; actual holdout sqrt((1-p)/(n*p)) <= 0.05; exact served-artifact calibration applied from validation; lower Brier and log loss than both constants; existing decision-88 calibration/subgroup gates satisfied; no unexplained subgroup or coverage failures. Proposed additional robustness bar: paired game-bootstrap improvement intervals exclude zero for both proper scores, subject to pre-registration before results. If evidence is too small, biased or incomplete, report NO-GO/insufficient evidence. Do not substitute the old 10-goal floor, merge calibration and test, or retune against a failed final test. A failed test becomes development evidence and a new final test is required.

Acceptance pack: source/data hashes; row and game manifest; exclusion/coverage report; feature lineage and leakage-test results; frozen split manifest; fit/convergence and tuning report; exact model/calibration artifact; scorer parity evidence; untouched evaluation with uncertainty; gate output and blockers; documented consumer scope. All candidates remain unapproved and offline. Stored historical results are preserved.
