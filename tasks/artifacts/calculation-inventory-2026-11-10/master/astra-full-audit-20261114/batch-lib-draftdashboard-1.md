### AFULL-LIBDRAFT1-01 — missing GP silently retains raw totals in 84-game valuation

- **Proposed P1, source-confirmed current call path; no live incidence claim.** `web/lib/draftDashboard/playerValues.ts:36–47` admits a finite points value when 84-game pacing is enabled even when the player's GP is unknown. `web/lib/projectionsConfig/proration.ts:73–81` returns the raw count when it cannot prorate, and `:115–127` sums that raw count into numeric FP. The fallback at playerValues:44 also retains the preexisting FP if recomputation is null.
- **Contract and consequence:** values sharing a paced valuation pool must have the same exposure basis. Missing exposure cannot establish an 84-game value. This is independent of partial active scoring (HOOK1-03): the fixture has every active scoring stat known, but no valid GP denominator.
- **Concrete exact-source fixture:** two C players each project 10 goals and 10 FP; score GOALS=1, prorate84=true. Player A has GP=null; B has GP=42. `buildPlayerValues` returns A=10, B=20; `canProrateStat(A,"GOALS")` is false. Expected A unknown/unavailable for this paced comparison, B=20. For A, this is a raw season total; for B, it is an 84-game pace.
- **Reader reach:** `web/hooks/useVORPCalculations.ts:163–173` accepts that values map. `web/components/DraftDashboard/DraftDashboard.tsx:2349–2379` passes the same prorate84 setting to ordinary and personalized VORP. Existing hooks1 full review traces these values to replacement/VORP/recommendations. In contrast, `web/lib/draftDashboard/tierDashboardAdapter.ts:24–28` explicitly rejects a missing denominator; `positionalTiers.test.ts:125–129` pins missing-GP players as missing. Thus two current readers disagree on the same eligibility condition.
- **Verification:** isolated exact-source probe exit0, receipt in manifest. TypeScript compiler only; imports stripped; exact forward grouping/FP/proration/value functions evaluated in VM. Category scoring unused and throw-if-called. No application import or React execution.
- **Suggested repair/regression:** enforce a shared required-exposure gate before paced FP enters the values map, keeping unknown as unknown. Add this two-player fixture to existing valuation tests and assert parity with tier admission; test GP=null/0 and absent active count inputs. Preserve goalie nonproration and authoritative zero weights.
