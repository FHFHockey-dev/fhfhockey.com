## Code

- `web/lib/projections/research/skater-candidates/accounting.ts`: assists = expected on-ice goals × shrunk assist share; no own-goal denominator, per-two-goals scale or arbitrary assist clamp. Complete-roster reconciliation targets a caller-supplied observed team A/G ratio, respects individual on-ice goal/own-goal capacities, and blocks missing or infeasible support. Separately allocates an explicit PK skater-seconds budget within player total-minus-PP capacities, subtracts PK before deriving ES, and projects SH count rates with explicit priors. Strength aggregation adds SH to G/A/SOG/SHP while PPP remains PP-only; unknown SH heads remain unknown.
- `priors.ts`: season-current F/D × ES/PP/SH count/exposure pooling for SOG/60, shooting %, assist share, IPP and G/A per 60. Enforces prior availability before the cutoff, unique player-game-strength identities and supported denominator pairs. Deterministic alternating-game split-half k search uses only other players' training halves for each direction's prior. The candidate grid is caller-supplied; units are shots, on-ice goals or hours. Empty input returns a blocker, not a suggested k. Grid boundary selection is reported. Tuning evidence needs an independent later cohort.
- `context.ts`: explicit ownership/channel contracts and duplicate-effect rejection. Shot danger changes finishing, not shot volume; an opponent-goalie effect reaches the goal environment once. Per-effect omission experiments start from identical neutral inputs. Poisson exposure-mixture variance uses the law of total variance without reducing the supplied expected opportunity or mean. No arbitrary role-stability-to-variance conversion is fitted here.
- `web/scripts/forge-skater-candidate-ablation.ts`: accepts a normalized `CandidateCohort` with any named baseline/candidates, heads, FP weights and dressed F/D player-games. Uses existing `summarize` and game-cluster-bootstrap implementations. Scores identical per-head support across all variants; excludes partial FP and duplicate identities. Reports bias, RMSE, Σactual/Σpredicted, descriptive MZ slope/intercept, seed-1 paired bootstrap deltas, own-head deciles, fixed baseline-head deciles and fixed baseline-expected-FP deciles. Deciles are calculated within each reported position group. Missing support counts are explicit. It does not automatically accept a model or assert predictive skill.

All helpers are isolated candidates with no runtime imports from the stage, no remote I/O and no default fitted constants. Synthetic test numbers are arithmetic fixtures only. Current `resolveSkaterConversionRates` already avoids the second conversion shrink for supported heads; Q7 still needs hydrated-current-cohort evidence, not another blind formula edit.
