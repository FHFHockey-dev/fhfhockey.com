## TJ: checkpoint versus overlap

Choose the inclusive latest-date overlap for this local repair. The existing `(goalie_id, date)` primary key (`supabase/migrations/20260716112908_production_schema_baseline.sql:33127`) makes replay idempotent without a migration or extra checkpoint writes. A structured fetch/write/prune failure already aborts the sweep; replaying the maximum persisted date therefore retries the date a partial write would otherwise advance past. Counts report rows successfully upserted, including already-present rows, rather than net new rows.

The replay starts at the latest stored date and uses each entrypoint’s existing forward loop. `incremental` includes today; the existing `action=all` loop can also include today despite reporting yesterday as its end boundary (see the independent-review correction below). It does not discover older holes if later rows already exist, a different writer advances the watermark, or non-structured errors let the sweep continue. An explicit `runMode=incremental&startDate=YYYY-MM-DD` can replay an older bounded range after separate operational authorization; no historical repair was executed. Same-goalie/two-game/same-date storage remains limited by the existing schema key.

A complete-date checkpoint could represent successful empty dates and avoid re-fetching completed dates, but requires durable checkpoint storage, an atomic completion protocol, initialization policy and coordination among every writer. It also cannot independently detect upstream omissions in an apparently successful response. That broader repair is unnecessary for this narrowly tested failure mode and is deferred.

Overlap cost: one additional stored date is reacquired and upserted on each automatic run. Normally three first-page source requests; existing pagination allows at most 25 pages × 3 sources (75 requests) before its guard fails. No pacing, concurrency, cron, environment or provider changes. Replays preserve prior rows when sources are empty or omit a former row; they do not certify provider completeness or delete obsolete rows with overwrite disabled.
