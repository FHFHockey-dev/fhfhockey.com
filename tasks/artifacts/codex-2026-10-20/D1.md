## Behavior

- Named shared policy: 40 requests/minute, 80/5 minutes, 100/15 minutes, 180/hour. Full jobs below 40 URLs may burst. Larger or unknown jobs use at least 21 seconds. Admission conservatively charges every network attempt, including retries, rather than assuming provider retry exemptions.
- `NstRequestControl.plannedRequestCount` describes the whole job, never the invocation cap or remaining suffix. Missing/invalid counts cannot enable a burst. Client defaults are paced; the gamelog route supplies the full plan. The local ledger shares rolling windows across keys and processes on the same filesystem and blocks concurrent canonical duplicate URLs.
- One full gamelog date normally means 20 league-wide URLs, independent of game count. Forty-URL jobs remain paced through the last short suffix. Paced chunks retain six source items; a small explicit scope can finish all 20 within its actual attempt/deadline limits.
- Explicit incremental/forward progress lives in acknowledged cron audit details, scoped by dates, selected datasets, refresh intent and the full source queue fingerprint. HTTP207 returns `operationStatus: continuation_required`, `resume.required: true`, and `resume.request.query` equal to the original query plus one increasing positive integer `cursor`. It advances only past acknowledged sources. Old-cursor replay and ordinary retries consult the latest confirmed progress, including completed scopes; explicit overwrite can refresh a completed scope.
- Provider/parse/write failure, missing/ambiguous cursor evidence, unknown write acknowledgement and unknown audit persistence stop automatic continuation. A zero-progress invocation is blocked rather than issuing a non-increasing cursor. Row samples never certify source completion, and source completion remains separate from coverage verification.
- Absolute caller `deadlineAt` is capped by maxRuntimeMs. NST/database work stops five seconds before it; the terminal audit awaits its lazy Supabase request inside the reserved AsyncLocalStorage deadline context. Retries share the original attempt budget.
- A positively known unstarted slate is a200 `skipped_no_completed_games` result with zero NST requests. Missing schedule dates block completion even beside known dates. Local `games` has no final/completed status: an elapsed start time is not proof of completion, so started slates still use existing source validation. No new provider lookup or schema change was added.
- Added evenStrength/penaltyKill dataset groups. Included the owned team-daily reverse-mode calendar fix and UTC boundary regressions.
