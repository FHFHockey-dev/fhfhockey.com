## Usability findings

1. **Phone navigation through a full roster is cumbersome.** With 20 synthetic players at 390×844, the Coverage heading was 5,474 CSS pixels from the document top; reaching it required 5,064 pixels of scrolling. The panel is reachable, and the two-player case has no horizontal overflow, but there is no shortcut between roster entry and coverage. Consider a mobile jump link or compact/collapsible roster in the next UI slice. Relevant layout: [component](../../../web/components/RosterAutopsy/RosterAutopsy.tsx) and [responsive styles](../../../web/components/RosterAutopsy/RosterAutopsy.module.scss).
2. **A copied or manually populated roster cannot be re-copied from RSO.** The actual browser shows the copy button disabled whenever the autopsy roster is nonempty. There is no in-product merge, replacement or clear-all action, so a user wanting a fresh copy must remove existing players individually. Consider a reviewable replace/merge flow that preserves current work. Relevant control: [RosterAutopsy.tsx](../../../web/components/RosterAutopsy/RosterAutopsy.tsx).

The route is accessible directly by URL in this local slice; no shared navigation link was added. Player-quality grades, league comparison, connected sync, trades and playoff schedules remain planned rather than verified functionality.
