# First approved deployment probe: what offline work cannot answer

**Before scheduling, the first deployment needs a separately approved probe.** Every item below is unknown offline. Each one either fails closed today or has a fallback, and the probe settles it. The probe must not claim a real date: run it with the kill switch **off** (a 200 `disabled` skip), or against a preview deployment, which gate 2 refuses with `deployment_not_production`. Both choices need TJ's approval, and a preview deploy also needs build approval.
