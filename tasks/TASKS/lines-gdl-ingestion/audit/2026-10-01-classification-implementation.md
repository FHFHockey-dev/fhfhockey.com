### ID-derived creation-time check

[Current X documentation](https://docs.x.com/fundamentals/x-ids) states that Snowflake IDs encode object creation time. [Twitter's archived generator](https://github.com/twitter-archive/snowflake/blob/snowflake-2010/src/main/scala/com/twitter/service/snowflake/IdWorker.scala) specifies epoch `1288834974657` milliseconds and a 22-bit timestamp shift. Using that documented layout, the local calculation was `new Date(Number((BigInt(id) >> 22n) + 1288834974657n)).toISOString()`; IDs were kept as strings/BigInt to avoid precision loss.
