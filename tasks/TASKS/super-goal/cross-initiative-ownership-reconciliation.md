## Reconciled invariants

1. Every persisted output above has one named writer/engine. Compatibility readers, UI adapters, and quarantined paths do not become alternate writers by being importable or historically documented.
2. Shared consumers read upstream stages in dependency order: raw source → normalized/relationship data → rolling/Sustainability context → FORGE outputs → UI/compatibility readers. A failed prerequisite is a bounded unavailable/partial state, not a synthetic success.
3. Scheduled ownership is separate from route authorization: the cron inventory identifies callers, while `adminOnly`, exact cron-secret, service-only SQL, and audit wrappers enforce admission and observability.
4. Historical repair, provider mutation, credential retirement, and Production natural-run evidence are not inferred from local code or value-free reads. They remain explicit gates in the owning source task lists.
5. The matrix does not create a second feature flag, model, persistence class, legacy history class, or provider owner.
